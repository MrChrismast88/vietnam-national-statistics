VietStats — Vietnam in Numbers. An original national statistics site for Viet Nam: population, economy, trade, labour, health, education, environment and every province, 2020–2024, with hand-rolled SVG charts, a year selector, sortable and filterable tables, and a data explorer — all as plain static files that run offline in a desktop browser and on a phone. Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
